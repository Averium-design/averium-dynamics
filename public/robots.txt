# Written 2026-08-22. Before this file existed, /robots.txt returned the React
# app: vercel.json rewrites everything unmatched to "/", so a crawler asking for
# robots.txt got 842 bytes of HTML with HTTP 200. Files in public/ are served
# before the rewrites, which is why putting a real file here is the whole fix.
#
# Nothing here is disallowed, and that is deliberate in one specific case:
# /sizeup and /sizeup-de carry "noindex" in a meta tag on the page itself. A
# crawler has to be allowed to fetch a page in order to read that tag. Blocking
# them here would leave them indexable-by-rumour - reachable through links,
# never re-checked, and impossible to remove. Do not add a Disallow for them.

User-agent: *
Allow: /

# changes it should change as a decision, in this file, with a date.
